## 🤍 About

**Style** is a responsive fashion website built around a calm, luxurious aesthetic: warm neutral tones, generous whitespace, bold editorial typography and large, confident imagery.

The goal was to capture a premium fashion-brand feel in a fast, lightweight front end, with no heavy frameworks, just thoughtful HTML and utility-first CSS.

<br>

## ✨ Highlights

| | |
|---|---|
| 🖼️ **Editorial hero** | Oversized typography layered behind the model for a magazine-style first impression |
| 📱 **Fully responsive** | Separate, optimized hero images for mobile and desktop |
| 🧭 **Refined navigation** | Clean header with minimal icons (search, account, cart) and a clear call to action |
| 🎨 **Cohesive palette** | Cream, sand and black that keep the whole page elegant |
| 🧱 **Semantic HTML** | `header`, `nav`, `main`, `section`, `article` for clarity and accessibility |
| 🌿 **Subtle motion** | Smooth hover states and soft transitions on interactive elements |
| 🌍 **Multilingual-ready** | Latin and Persian fonts bundled locally |

## 🚀 Getting Started

**1 · Clone the repository**

```bash
git clone https://github.com/sara-nejat/style.git
cd style
```

**2 · Install dependencies**

```bash
npm install
```

**3 · Build the CSS**

```bash
npx @tailwindcss/cli -i ./assets/css/input.css -o ./assets/css/output.css --watch
```

**4 · Open the site**

Open `index.html` in your browser, or use a local server such as the VS Code *Live Server* extension.

<br>

## 💡 Design Notes

> **Mobile first.** Layouts are designed for small screens and scale up through Tailwind's `md` and `lg` breakpoints.

> **Art direction.** The hero uses different images per device, so the composition stays strong at every size.

> **Restraint.** A limited palette and a small set of type styles keep the interface calm and premium.
